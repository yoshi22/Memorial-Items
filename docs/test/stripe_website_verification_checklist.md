# stripe_website_verification_checklist.md

> **Phase 3 用**。Stripe website verification が再開するまで使用しない。Phase 1/2 では本ドキュメントは参照不要。

## Purpose
Stripe の website verification 再審査前に、公開サイトが最低限の公開情報を満たしているか確認する。

## Page checks
- `/` にサービス概要、支払い方法、納品目安、返金方針がある
- `/faq` に問い合わせ先とサービス概要がある
- `/order` に注文前確認事項がある
- `/contact` に問い合わせ手段と返信目安がある
- `/legal/commerce` に事業者情報、販売条件、納品条件がある
- `/legal/privacy` に個人情報の扱いがある
- `/legal/terms` に利用条件がある
- `/legal/refund-policy` に返金・キャンセルの考え方がある
- `/legal/delivery` に納品形式とリードタイムがある

## Footer checks
- すべての public page で footer が表示される
- footer から `contact` と `legal/*` へ遷移できる

## Content consistency
- physical shipping を現行提供中と誤認させる文言がない
- digital delivery が current release と一致している
- 問い合わせ先、返金方針、納期が各ページで矛盾しない
