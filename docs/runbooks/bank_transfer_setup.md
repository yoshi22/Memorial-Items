# bank_transfer_setup.md

## Purpose
銀行振込決済（Phase 1）の口座準備・env 設定・入金確認運用・トラブル対応をまとめる。

---

## 1. 振込先口座の準備

### 用意するもの
サービス専用口座を用意することを推奨する（既存口座でも可）。

| 項目 | 説明 |
|------|------|
| 銀行名 | 例: ゆうちょ銀行、三井住友銀行 |
| 支店名 | 任意（記載しない場合は省略） |
| 口座種別 | 普通 / 当座 |
| 口座番号 | 7桁 |
| 口座名義 | カタカナ表記 |
| 振込参考文言 | 顧客への案内文。例: 「ペットのお名前をご記入ください」 |

### 推奨
- 事業用口座を分けると入金管理が楽になる
- 屋号名義の口座があると信頼感が上がる

---

## 2. 環境変数の意味と設定値

| 変数名 | 必須 | 説明 |
|--------|------|------|
| `BANK_TRANSFER_BANK_NAME` | ○ | 銀行名。例: `三井住友銀行` |
| `BANK_TRANSFER_BRANCH_NAME` | — | 支店名。例: `渋谷支店` |
| `BANK_TRANSFER_ACCOUNT_TYPE` | — | 口座種別。例: `普通`（デフォルト: 普通） |
| `BANK_TRANSFER_ACCOUNT_NUMBER` | ○ | 口座番号。例: `1234567` |
| `BANK_TRANSFER_ACCOUNT_HOLDER` | ○ | 口座名義（カタカナ）。例: `メモリアル　タロウ` |
| `BANK_TRANSFER_REFERENCE` | — | 顧客への振込人名案内文。例: `ペット名をご記入ください` |

BANK_NAME / ACCOUNT_NUMBER / ACCOUNT_HOLDER の 3 項目が揃えば振込案内が有効になる。

---

## 3. Vercel への登録手順

1. Vercel Dashboard を開く
2. `memorial-items` プロジェクトを開く
3. `Settings` > `Environment Variables` を開く
4. 6 項目を `Production` に追加する
5. `Deployments` から最新 deployment を `Redeploy` する

登録後に `/order` から注文し、注文完了画面に振込先が表示されることを確認する。

---

## 4. 入金確認の運用フロー

1. 顧客が注文を送信する → 注文受付メールに振込先情報が含まれる
2. 顧客が指定口座に振込む（ペット名を振込人名に含めてもらう）
3. 通帳または銀行アプリで入金を確認する
4. 管理画面 `/admin/orders/[id]` で `payment_status` を `paid` に更新する
5. `paid` 更新時に顧客へ支払い確認メールが自動送信される

---

## 5. 振込人名の照合のコツ

顧客に対して「振込人名にペット名を含めてください」と案内する（`BANK_TRANSFER_REFERENCE` に記載）。

照合に使える情報:
- 振込人名（ペット名が含まれていることが多い）
- 振込金額（注文時に案内した金額と照合）
- 振込日（注文日から数日以内であることが多い）

不明な入金が続く場合は、顧客に確認メールを送る。

---

## 6. 入金前キャンセルへの対応

注文が `new` または `in_review` の段階でキャンセルが必要な場合:

1. 管理画面で注文ステータスを `cancelled` に更新する
2. 顧客に個別メールでキャンセルを通知する（現時点でキャンセルメールは自動送信されない）
3. 入金済みの場合は手動で返金手続きを行う

---

## 7. Phase 2（PayPay 追加）

Phase 2 は実装済み・現在保留中。PayPay を有効化するには Vercel に `PAYPAY_PAYMENT_URL` または `PAYPAY_QR_IMAGE_URL` を追加して再デプロイするだけでよい（コード変更不要）。

詳細（個人事業主向け加盟店申込・資産入手手順・運用フロー）は `docs/runbooks/paypay_setup.md` を参照。

## 8. トラブルシューティング

### 振込案内が表示されない
- `BANK_TRANSFER_BANK_NAME` / `BANK_TRANSFER_ACCOUNT_NUMBER` / `BANK_TRANSFER_ACCOUNT_HOLDER` の 3 項目が Production に設定されているか確認する
- 再デプロイ後に確認する

### 口座情報を変更したい
- Vercel の env を更新して再デプロイするだけでよい
- コード変更は不要

### 口座情報を一時的に非表示にしたい
- `BANK_TRANSFER_BANK_NAME` を空にすると振込案内が無効になる
- 注文フォームの支払い方法選択も消えるため、注文を受け付けられない状態になる
