# content_update.md

## Purpose
examples と FAQ を更新する手順。

## Examples update
### Add new example
1. 画像使用許諾を確認
2. 画像を examples bucket にアップロード
3. title / short description / tags を登録
4. examples page で表示確認

### Rules
- 個人情報を含めない
- ペット名掲載は許諾がある場合のみ
- before/after を出す場合は誇張しない
- 似ていることを過剰表現しない

## FAQ update
### Add FAQ
1. 実際に問い合わせが多いか確認
2. 既存 FAQ と重複しないか確認
3. answer は曖昧表現を避ける
4. 変更後、注文導線に悪影響がないか確認

## Copy rules
- できること / できないことを明確に書く
- "ケースによります" を多用しない
- 納期や修正回数などのルールは最新運用と一致させる

## Review checklist
- 誤字脱字
- 許諾確認
- 画像の公開範囲
- tone of voice 一貫性
