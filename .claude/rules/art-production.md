# art-production.md

## Goal
proof と print master を安定して作れるようにする。

## Rules
- スタイルは固定3種以内
- must_keep_features を必ず読む
- 参考写真は選定して記録する
- proof と print master を分ける
- 版管理を行う
- 顧客承認前に印刷しない
- 人間QAを必須にする
- 修正履歴を残す

## Quality priorities
1. likeness
2. print safety
3. style consistency
4. turnaround speed

## Do not
- 完全自動化を前提にしない
- proof をそのまま印刷データに使わない
- 古い proof version を上書きして消さない
