# frontend.md

## Goal
顧客が迷わず注文し、迷わず proof を確認できるUIを作る。

## Rules
- 1画面1責務を徹底する
- 注文導線を最短にする
- フォームは必要最小限
- UI の自由度より不安解消を優先する
- order form では写真ガイドを明示する
- proof page では「承認」「修正依頼」を大きく明確に分ける
- 管理画面は操作速度優先
- 派手なアニメーション禁止
- 独自コンポーネント乱造禁止
- shadcn/ui ベースを優先する

## Do not
- 将来の商品拡張を前提にした複雑な selector UI を作らない
- customer account 前提の UI を混ぜない
- "AI生成中" のような不要な概念を見せない
