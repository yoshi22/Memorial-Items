# implement-feature / prompt

Implement the following feature within current MVP scope only.

Before coding:
1. Read `docs/specs/current_release.md`
2. Confirm the feature is in scope
3. Keep implementation manual-first and minimal

Requirements:
- Do not introduce future-proof abstractions
- Reuse existing patterns
- Update schema/migrations only if necessary
- Update docs if flow changes
- Add tests for critical path

Output:
- changed files
- short implementation summary
- risks / TODOs
