# implement-feature / README

## Purpose
MVP スコープ内の機能を、余計な抽象化なしで実装するための手順。

## Workflow
1. `docs/specs/current_release.md` を読む
2. スコープ内か確認する
3. 影響範囲を洗う
4. 最小設計を決める
5. 実装する
6. 必要なテストを書く
7. docs を最小更新する

## Principles
- simplest thing that works
- manual-first
- no future-proofing
- no extra abstractions
